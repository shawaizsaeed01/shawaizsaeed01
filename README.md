### 🏗️ Infrastructure as Code

I use **Terraform** to turn infrastructure into version-controlled, repeatable, auditable code.

```text
Terraform
    ↓
AWS / Azure Infrastructure
    ↓
Networking + Compute + Security
    ↓
Application Platform
    ↓
CI/CD + Monitoring
```

This allows infrastructure changes to be reviewed, automated, reproduced, and consistently deployed across environments.

## 🧩 Architecture Mindset

I don't treat DevOps as simply "deploying applications."

I focus on building systems that are:

```text
             ┌─────────────────────┐
             │   Application       │
             └──────────┬──────────┘
                        │
                ┌───────▼───────┐
                │   Containers   │
                │ Docker / ECS   │
                │ Kubernetes     │
                └───────┬───────┘
                        │
              ┌─────────▼─────────┐
              │   CI/CD Pipeline   │
              │ Build → Test →     │
              │ Scan → Deploy      │
              └─────────┬─────────┘
                        │
          ┌─────────────▼─────────────┐
          │      Cloud Platform       │
          │       AWS / Azure         │
          └─────────────┬─────────────┘
                        │
       ┌────────────────┼────────────────┐
       │                │                │
   Security         Monitoring       Automation
   IAM              Metrics          Terraform
   Secrets          Logs             GitOps
   Scanning         Alerts           IaC
       │                │                │
       └────────────────┼────────────────┘
                        │
                🚀 Reliable Production
```

### My core principles

* **Automation over manual operations**
* **Infrastructure as Code over click-ops**
* **Security from the beginning**
* **Observability by design**
* **Least privilege by default**
* **Immutable and repeatable deployments**
* **High availability where business requirements demand it**
* **Simple architecture before unnecessary complexity**
* **Measure before optimizing**
* **Design for failure**
